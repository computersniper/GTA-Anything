# GtaAnything.Runtime — Clean-Room C# Runtime Compatibility Layer

`GtaAnything.Runtime` is the **100% clean-room C# runtime compatibility and safety SDK** for mods generated by the `GTA-Anything` transpiler (`gta_anything.transpiler.csharp_codegen`).

Inspired by the clean-room runtime and ABI relinking philosophy of `AnyPS5` and `XenonRecomp`, this project contains **zero proprietary Rockstar or third-party binary `.dll` / `.asi` files** and builds standalone out-of-the-box via `dotnet build` on any standard .NET SDK (`netstandard2.0`).

---

## 1. Architectural Invariants Enforced by the Runtime

| Invariant | Runtime Class | Guarantee |
| :--- | :--- | :--- |
| **Dual Build ID & Gen8/Gen9 Detection** | `Compatibility.GameEditionDetector` / `GameBuildInfo` | Tracks both disk executable version (e.g. `1.0.1158.16`) and Script Hook V enum alias (e.g. `VER_EN_1_0_1158_13`); flags Gen9 `script_rt_*` `B8G8R8A8_UNORM` requirement and expected `.yft` (`171`) / `.ytd` (`5`) versions. |
| **Loader & Hotkey Chord Guard** | `Compatibility.LoaderAdapter` / `HotkeyChord` | Abstracts `SHVDN v3`, `SHVDN Enhanced`, and `RPH` lifecycle ticks, keydowns, and aborts; enforces modifier chords and story-mode / on-duty guards. |
| **Lease-Based Entity Cleanup** | `Lifecycle.WorldSession` | Registers only mod-created vehicles, peds, blips, and cameras (`LeaseVehicle`, `LeasePed`, `LeaseBlip`, `LeaseCamera`) and deterministically releases them on `DisposeAll()` without touching vanilla or other plugins' entities. |
| **Full Operational State Machine** | `Lifecycle.OperationalStateMachine` | Enforces valid transitions across `Idle` → `MenuSelecting` → `ResourceStreaming` → `SpawningShift` → `ActiveOperation` → `Completing` → `Teardown`, automatically forcing `Teardown` on unhandled exceptions. |
| **Gate 3 & Gate 4 Safe Model Streaming** | `Streaming.SafeModelStreamer` | Polls model streaming with bounded timeout, **mandatorily calls `ReleaseModelRequest` (`MarkAsNoLongerNeeded`) on timeout**, falls back to `vanillaFallbackModel`, and null-guards `SpawnVehicle`. |
| **UI-Spawn Decoupling** | `UI.DecoupledMenuController` | Restricts menu scrolling (`OnIndexChanged`) to `StaticMenuCard` metadata and 2D sprite descriptors (`StaticMetadata` / `StaticSprite`), structurally preventing `NullReferenceException` from live 3D vehicle preview spawning. |
| **7-Layer Acceptance Telemetry** | `Telemetry.PhasedJsonLogger` | Emits structured `.jsonl` records (`L1`–`L7`) consumed by `gta-anything diagnose` for multi-log timestamp correlation. |

## 2. Conditional Compilation Symbols

Pass `-p:GtaEdition=Enhanced` (default) or `-p:GtaEdition=Legacy` and `-p:GtaLoader=SHVDN` or `-p:GtaLoader=RPH` during `dotnet build`:

- `GTAV_ENHANCED`: Targets GTA V Enhanced (Gen9 asset pipeline: `.yft` v171, `.ytd` v5, `script_rt_*` single-mip `B8G8R8A8_UNORM`).
- `GTAV_LEGACY`: Targets GTA V Legacy (Gen8 asset pipeline: `.yft` v162, `.ytd` v13).
- `USE_SHVDN`: Targets the `ScriptHookV.dll` + `ScriptHookVDotNet.asi` (`scripts/`) loader chain.
- `USE_RPH`: Targets the `RAGEPluginHook.exe` (`plugins/`) loader chain.

```bash
# Default Gen9 Enhanced build
dotnet build runtime/csharp/GtaAnything.Runtime/GtaAnything.Runtime.csproj

# Gen8 Legacy build
dotnet build runtime/csharp/GtaAnything.Runtime/GtaAnything.Runtime.csproj -p:GtaEdition=Legacy
```
